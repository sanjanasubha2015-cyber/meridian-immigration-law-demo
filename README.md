# Meridian Immigration Law — Portfolio Demo

A one-page fictional website for a boutique U.S. immigration practice. Built as a Fiverr web-development portfolio piece for **Touch of Ash**.

This is not a real law firm. Every attorney, matter, testimonial, insight, and Houston address on the page is invented for demonstration only.

## Design

The layout follows the visual habits of elite editorial legal sites: oversized serif headlines, generous whitespace, thin rules, a precise grid, and a restrained palette of navy, ivory, charcoal, and champagne gold. Practice areas and matters are presented as rows, not cards. There are no gavels, scales, or stock-courthouse images.

Photography in `/images` is placeholder architectural and portrait work and can be replaced with licensed photography.

## Stack

- Semantic HTML
- Handwritten CSS (Grid, Flexbox, `clamp()` typography)
- Google Fonts: Cormorant Garamond and Manrope
- No JavaScript
- No CSS frameworks
